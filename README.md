# Dynamic MLFQ OS Simulator 🖥️⚙️

A graphical, real-time simulator for the Multilevel Feedback Queue (MLFQ) CPU scheduling algorithm. Built with Python and Tkinter, this tool visualizes complex operating system process management, including queue demotions and resource allocation.

## 🌟 Features
* **Interactive GUI:** Built with Tkinter to provide a clear, visual representation of CPU scheduling.
* **Real-Time Animations:** Watch processes move between queues dynamically as their execution time progresses.
* **Waterfall Demotions:** Accurately simulates priority degradation when a process exceeds its time quantum.
* **Customizable Parameters:** Easily adjust time quantums, process arrival times, and burst times to see how the MLFQ responds to different scenarios.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **GUI Framework:** Tkinter
* **Core Concepts:** Data Structures, Operating Systems, Process Scheduling Algorithms
